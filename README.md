## Project Overview

The **Connect Tutors SA** is a mobile application developed as part of an assignment in the Web development subject. This application was created using **Visual Studio Code**. The app's primary purpose is to help students improve their marks and have access to free tutors. This happens through a booking system where learners can book a tutor for a specific subject, the student has to explain their learning styles and problems that they are facing academically so they can get the help they need.
The website was developed to meet the requirements of the assignment, which includes creating a functional web page.

---

## Purpose and Features

### Purpose:
The main goal of this app is to ensure that students get their academic spark back and feel motivated and confident in their schoolwork and improve. It is to also ensure that all students have access to education despite their financial situation back home. 

### Key Features:
- Feature 1: Dynamic tutor profiles with profile pictures and subject information.
- Feature 2: Tutor search functionality by name and subject.
- Feature 3: Individual tutor profile viewing.
- Feature 4: Interactive FAQ feature for users.
- Feature 5: Interactive map displaying locations in some parts of South Africa.
- Feature 6: Random study tips generator.
- Feature 7: Educational gallery showcasing students with lightbox functionality.
- Feature 8: Volunteer tutor enquiry form.
- Feature 9: Contact information and social media platforms where people can contact Connect Tutors SA.
- Feature 10: Responsive design for mobile, tablet and desktop devices.
- Feature 11:Search Engine Optimisation (SEO).

These features aim to provide an easy to understand and navigate website for users despite their exposure to technology.

---
### Design Considerations 
The design of the **Connect Tutors SA** was based on the following key considerations: 

1. User Experience (UX): The website was designed with the goal of providing an intuitive and easy-to-navigate user interface, ensuring a seamless user experience.
2. Respnsiveness: The website was built to ensure it performs well on different screen sizes, paying careful attention to device compatibility.
3. Simplicity: The design is minimalistic, focusing on core features without overwhelming the user.
4. Performance: Code optimisation was considered to ensure fast response times and low battery usage.

### Challenges and Learnings 
1.## Challenges and Solutions

1. **Tutor Image Display**: Tutor images initially failed to load due to incorrect image paths.
2. **Solution**: This was resolved by correcting the filenames in JavaScript.

3. **Tutor Search Functionality:** Implementing dynamic tutor filtering was challenging.
4. **Solution**: We overcame this by using JavaScript event listeners.

5. **Interactive Map**: The initial map tiles returned a 403 error.
6. **Solution**:  We resolved this by switching to an ArcGIS basemap using Leaflet.js.

7. ## Future Enhancements
